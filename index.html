CWNK Restaurant - ระบบจัดการร้านอาหาร

รายละเอียดโปรเจค

CWNK Restaurant เป็นระบบจัดการร้านอาหารที่ครบวงจร พัฒนาด้วย Python Django Framework โดยมีฟีเจอร์หลักดังนี้:

ฟีเจอร์หลัก

  • ระบบจัดการเมนูอาหาร - เพิ่ม/แก้ไข/ลบรายการอาหาร พร้อมรูปภาพ
  • ระบบสั่งอาหาร - บันทึกออเดอร์ แก้ไขรายการ และติดตามสถานะ
  • ระบบจัดการโต๊ะ - จองโต๊ะ ตรวจสอบสถานะ
  • ระบบชำระเงิน - คำนวณราคา ออกใบเสร็จ
  • รายงานและสถิติ - สรุปยอดขาย รายงานประจำวัน/เดือน
  • ระบบสมาชิก - จัดการผู้ใช้งาน กำหนดสิทธิ์

เทคโนโลยีที่ใช้

  • Backend: Python Django
  • Frontend: HTML, CSS, JavaScript, Bootstrap
  • Database: PostgreSQL
  • Authentication: Django Authentication System
  • UI Components: Bootstrap 5
